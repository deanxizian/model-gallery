# Model Gallery

这是我个人数码产品的数字化收藏，收录正在使用和已经退役的设备。通过 3D 模型保留它们的外观，也记录购入时间、实际配置和使用回忆。

[打开网站 · Vercel](https://model-gallery-dean.vercel.app/) · [备用入口 · GitHub Pages](https://deanxizian.github.io/model-gallery/)

## 这里有什么

- 手机、电脑、手表、耳机、阅读器等设备的 3D 模型。
- 每件设备的购入时间、实际规格，以及「在役 / 已退役」状态。
- 设备的相关配件，例如阅星瞳 X3 页面中的充电底座和 Type-C 充电转接头。

## 怎么浏览

选择一件设备，就能拖动旋转、缩放或全屏查看模型。也可以搜索名称，按品牌或使用状态筛选；设备默认按购入时间从近到远排列。

模型下方可以查看拥有记录，展开「参数规格」了解更多。点击「下载模型」选择所需格式，具体提供哪些格式以该模型的下载菜单为准。

手机上可以左右滑动设备列表，用双指缩放模型。

## 在本地打开

需要先安装 Node.js 24 和 pnpm 11.19.0。在项目文件夹中运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

然后打开终端中显示的本地网址。

## 添加或更新内容

设备的模型、封面和资料统一放在 `public/models/`，每件设备一个文件夹，配件放在所属设备下面。项目说明集中在 `docs/`，详细目录和添加步骤见 [模型添加与项目维护](docs/maintenance.md)。

修改先在分支中完成，检查后再提交 PR，经过 GitHub Codex Code Review 审核后合并。合并到主分支后，两个网站会自动更新。

## 模型来源

阅星瞳 X3 及其配件来自个人建模项目；Apple 产品模型来自 Apple 公开的 AR 资源。具体来源保留在各产品的资料文件中，第三方模型与商标的权利归各自权利人，本项目不另行授予许可。

外观模型用于展示。下载 X3 底座用于 3D 打印时，夹紧程度和充电接触仍需试装确认。
