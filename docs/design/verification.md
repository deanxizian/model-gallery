布局参考为 [concept.png](concept.png)，实际渲染为 [desktop.png](desktop.png)。使用 Codex 内置浏览器测试，并在同一轮验收中用 `view_image` 分别检查两张图片；桌面视口与概念图均为 1536 × 1024。手机按 390 × 844 检查，截图见 [mobile.png](mobile.png)。

| 对照项 | 概念图与实现证据 | 处理 |
| --- | --- | --- |
| 页面结构 | 74 px 白色页头、380 px 左侧模型列表、右侧浅灰预览区和底部说明 | 保留同一结构与边界位置，没有加入营销区块 |
| 文案 | 品牌、模型标题、搜索、旋转/重置、下载 STL 与 STEP | 与 `spec.md` 文案表逐项核对；无遗漏，补充的“模型说明”为真实配合信息 |
| 字体 | 品牌 25 px、模型标题 30 px、目录标题 22 px、控制按钮 17 px | 使用系统中文无衬线字体，按钮和辅助文字均明确指定字号 |
| 颜色与容器 | 白色页头/侧栏、#f1f2f3 预览背景、浅蓝选中行、深色主下载按钮 | 保持配色和开放画布；未增加渐变覆盖、装饰徽标或额外卡片 |
| 模型素材 | 概念图中的 X3 外形和底座为生成式近似；实现采用现有真实 STL/GLB | 有意替换为准确资产，并沿用实际模型缩略图；不复刻错误产品形状 |
| 模型光照 | 首次渲染白色过亮，凹槽不清楚 | 使用 ACES 色调映射、调整预览材质和照明，保留真实几何和原始下载字节 |
| 控件与留白 | 概念图有浮动旋转/重置栏和右上全屏 | 沿用对应线条图标；缩短 WebGL 画布有效高度，使模型不遮挡控制栏 |
| 手机 | 同一界面在窄屏需要保留目录与下载 | 模型列表横向滚动；正文无水平溢出，详情及下载纵向排列 |

首屏文案差异：额外的“模型说明”是设计规范允许的真实信息入口；加载、错误、空搜索和手机手势提示仅在对应状态出现。模型名称、尺寸和版本取自实际文件的元数据。

保留的有意差异：用真实模型替换概念图的近似模型；实际缩略图沿用现有工作室渲染背景；相机按真实模型体积取景，模型占比不复制概念图中错误的几何比例。没有待修复的布局或交互阻碍。

## 交互与构建

- 三个模型均在内置浏览器加载并目视检查，切换同步更新标题、描述、下载地址和 URL。
- 搜索 X3 显示两项，无法匹配时显示空结果；清除搜索恢复目录。
- 自动旋转切换为暂停状态；重置恢复默认相机并停止旋转。
- 全屏进入和退出正常。手机可滚动到完整详情及下载入口。
- 正式构建中的 STL 下载入口调用成功；HTTP 获取的 STL 与本地送印原件 SHA-256 一致。
- 手机页面滚动宽度不超过视口；正式构建浏览器未记录 JavaScript 错误。
- `pnpm test` 三项通过；`pnpm build` 通过；`pnpm peers check` 无依赖冲突。

以上是网页与文件发布链路验证，不是对打印材料、公差或实物配合的新增承诺。
